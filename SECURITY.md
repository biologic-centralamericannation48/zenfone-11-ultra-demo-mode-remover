# Security Policy

This utility performs one destructive operation after strict device checks. Please report safety bugs through GitHub private vulnerability reporting rather than publishing an exploit or dangerous command sequence in an issue.

Reports should include the script version, sanitized console output, phone model, firmware build, and whether any command changed device state. Remove serial numbers, IMEIs, account addresses, and other personal information.

The project does not accept requests to bypass device ownership, account protection, enterprise policy, bootloader authorization, or service-tool authentication.
